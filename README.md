# CodeCollab 

**Collaborate, Compete, and Conquer Coding Together**

CodeCollab is a platform that helps students practice Data Structures & Algorithms (DSA) collaboratively with friends. It keeps users motivated by combining **real-time collaboration, structured problem-solving, and competitive leaderboards**.

---

##  Problem Statement

Many students lose consistency while practicing coding alone.
There is no structured way to:

* Practice with friends
* Track progress together
* Stay motivated consistently

---

## 💡 Solution

CodeCollab solves this by providing:

* Shared coding rooms
* Structured problem lists
* Leaderboards for competition
* Progress tracking using coding platforms

---

##  Features

### Authentication

* Login using Google authentication

### Dashboard

* Create and manage coding rooms
* View all your active rooms
* Organized topics (DP, Graphs, Trees, etc.)

### Problem Management

* Add problems inside rooms
* Track status (Solved / To-Do)
* Categorized by difficulty

### 🏆 Leaderboard

* See rankings among friends
* Track number of problems solved
* Monitor progress in real-time

### 👥 Collaboration

* Invite friends via email or user ID
* Join shared coding rooms

### 🔗 Platform Integration

* Connect your:

  * LeetCode username
  * GeeksforGeeks username
* Automatically track progress

---

## Tech Stack

* **Frontend:** React
* **Backend:** firebase
* **Authentication:** Google OAuth

---

## ⚙️ How It Works

1. Sign in using Google
2. Add your LeetCode / GFG username
3. Create or join a room
4. Add problems and start solving
5. Track progress and compete via leaderboard
